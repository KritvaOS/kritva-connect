# Acceptance Criteria: kritva-connect

Standard: kritva-program `v2/planning/ACCEPTANCE_STANDARD.md`. Criteria for each task live with the task in `tasks/KOS-CONNECT-NNN/ACCEPTANCE_CRITERIA.md`. Only [KOS-CONNECT-001](tasks/KOS-CONNECT-001/ACCEPTANCE_CRITERIA.md) has criteria so far, and they are PROPOSED, not reviewed.

General rules for every task here:

1. Software and simulation acceptance is never described as physical or safety validation.
2. A task is complete only through a central approval in kritva-program bound to immutable evidence; a merge or tag here creates no credit.
3. No secret, key or LiveKit project identifier is committed.
4. A fixed defect adds a regression test.
